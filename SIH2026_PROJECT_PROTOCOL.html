1. Executive Protocol Summary

This protocol establishes the mandatory technical architecture, standard operating procedures (SOP), automated assessment rubrics, and data communication rules for Team ALTRIX's SIH 2026 Project. It bridges the 6-slide presentation format with concrete engineering specifications required during institutional and jury reviews.

2. Standard Operating Procedure (6-Stage Closed-Loop Protocol)

The platform operates through an automated cyclical protocol guaranteeing role-competency alignment:

Stage 01
Role Ingestion
Ingests competency requirements per designation using national FRAC frameworks.
Stage 02
Diagnostic Assessment
Administers situational & knowledge screening to establish learner baseline.
Stage 03
Skill-Gap Diagnostic
Calculates differential competency vector: ΔC = Target Level - Baseline Level.
Stage 04
Curriculum Synthesis
RAG engine matches precise iGOT Karmayogi modules to bridge identified deficiencies.
Stage 05
In-Situ Adaptive Testing
Dynamically generates contextual quizzes grounded in verified course materials.
Stage 06
Dynamic Re-Indexing
Updates officer competency scores on verified completion, feeding continuous upskilling.

3. System Architecture & Technical Communication Protocol

Frontend Client Tier:

React.js 18 with Tailwind CSS. Communicates via secure RESTful JSON (TLS 1.3) and WebSocket connections for live evaluation streams.

API Gateway & Service Mesh:

Java Spring Boot 3.x enforcing Role-Based Access Control (RBAC), JWT token lifecycle management, and rate limiting.

AI Inference Microservice:

Python 3.11 with FastAPI. Executes LangChain/LlamaIndex RAG pipelines with strict JSON-schema output enforcement.

Data Persistence & Vector Store:

PostgreSQL 16 with pgvector extension for sub-30ms semantic course retrieval using HNSW indexing.

4. Evaluation Rubric & Mathematical Scoring Protocol

Learner competency scoring is governed by a deterministic, transparent formula to prevent subjective grading:

Composite Competency Index (CCI) = (0.40 × Kdomain) + (0.35 × Rreasoning) + (0.25 × Aapplication)
Proficiency Band Score Range Diagnostic Status Prescribed Action Protocol
Tier 1: Expert 85 – 100 Deployment Ready Issue official competency certificate; unlock advanced modules.
Tier 2: Proficient 70 – 84 Core Competencies Met Approved for standard designation duties; quarterly refresher.
Tier 3: Developing 50 – 69 Moderate Skill Gap Mandatory 2-week targeted micro-learning remediation.
Tier 4: Critical Gap < 50 Substantial Deficiency Automated alert dispatched to training supervisor; baseline restart.

5. Security, Risk & Guardrails Protocol

  • Zero Hallucination Guardrail: Assessment generation prompts are constrained to exact contextual excerpts retrieved from verified government curriculum files.
  • Data Privacy & Sovereignty: Learner performance telemetry and PII are encrypted using AES-256 at rest and TLS 1.3 in transit with on-premise government cloud compliance.
  • Fallback Protocol: If vector search latency exceeds 2000ms, the system gracefully falls back to pre-indexed taxonomic keyword caches.
